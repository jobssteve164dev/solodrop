# SoloDrop 套餐与付费接入

## 已确认产品契约

SoloDrop 用于临时预览和传阅文件。官网与 VS Code 插件使用同一账号、同一订阅和同一分享服务；免费分享无需登录，不以注册或购买阻塞首次分享。

| 项目 | Free | Pro |
| --- | --- | --- |
| 价格 | 免费 | USD 5/月，或 USD 49/年（一次收取） |
| 有效期 | 24 小时 | 可选 1、7、30 天，最长 30 天 |
| 单文件 | 10 MiB | 100 MiB |
| 同时保存的分享内容 | 临时分享 | 5 GiB；仅用于有效期内的分享，不提供长期存储 |
| 预览、下载控制、文字水印 | 支持 | 支持 |
| 访问密码、移除 SoloDrop 品牌 | 不包含 | 支持 |

月付和年付权益相同，只按付款周期区分。所有新分享都必须有明确到期时间，禁止 `never`；登录本身不授予 Pro 权益。订阅到期影响新分享的可用选项，已经成功创建的分享遵守创建时的到期时间。历史无期限分享保持原记录，不在本次上线中追溯删除或缩短。

## 权威与接入路径

SZLKPassport 是套餐、金额、币种、周期、付费权益与额度的唯一可变权威；本文件记录用户确认的初始配置，运行时不得用文档或本地常量兜底付费目录。

- 产品身份：`solodrop`；月付计划 `solodrop_pro_monthly`，年付计划 `solodrop_pro_yearly`。
- UI 语义键：`pro_monthly`、`pro_yearly`；共同权益：`pro_sharing`。
- 价格键：`solodrop.pro.monthly`、`solodrop.pro.yearly`。不复用 SoloMap 的产品、凭据、价格或权益。
- 服务端使用现有 SoloDrop Passport 凭据，读取目录、创建结账链接、读取账务并查验访问。用户身份来自本地已验证会话，拒绝客户端指定购买者或金额。
- 结账回跳固定到 `https://drop.szlk.ai` 的对应语言页面。回跳不等于支付成功，必须查验 Passport 权益。
- 插件沿 SoloMap 的浏览器授权与设备轮询模式连接现有网站账号；会话仅保存在 VS Code SecretStorage，不进入 Webview 或分享链接。
- 访问密码只保存加盐派生值。预览、文件原内容、下载和 Range 请求共用访问保护；不会只隐藏页面入口。
- 去品牌在生成预览时由服务端确认，不允许客户端绕过权益校验。
- 额度在现有 Durable Object 中为文件上传预留，失败释放；主动删除、到期后释放，防止并发上传绕过额度。

## 先例映射与差异验证

SoloMap `website/src/worker.js` 的目录读取、当前身份结账、Passport access-check、浏览器授权及设备确认是接入先例。SoloDrop 复用这些协议和责任边界，保留自己的 Headless 登录和 R2 分享链路。

差异是两种付款周期、临时文件权限及官网/插件上传。验证必须覆盖两份目录报价、当前身份绑定、付款回跳未授予权益、Free 与 Pro 有效期、密码旁路、去品牌、额度并发、订阅失效和设备授权隔离。

## 实施与发布验收

1. 受治理工具完成套餐、支付路由及清理权限申请；首次共享写入前记录精确配置、验收对象和稳定操作 ID。
2. 按实时 Passport 帮助合同配置两个计划；支付路由使用逐项预览、精确批准、应用、读回，不替换共享项目数组。
3. 行为回归先失败再实现；本地完整 Worker 验证真实入口、SQL、R2、最终脚本语法、浏览器初始化与中英文页面。
4. 两个计划分别通过受治理 Stripe Test Mode 交易、正式 webhook、权益与访问检查；清理临时测试对象，保留不可变审计。不进行真实资金扣款。
5. 独立代码审查、编译、测试、Worker 构建、依赖安全检查通过后，提交推送并沿现有 GitHub Actions 发布与核验。

## 当前验证范围

0.0.40 已实现上述官网、插件、服务端与账号路径。本地 `npm run check:all` 通过 73 项测试及 Worker 构建；`npm audit` 为零漏洞；最终 VSIX 已核对排除内部指令与浏览器验收文件。

隔离 Worker 已验证 100 MiB 上传、密码保护、首尾 Range 读取、所有者删除、容量预留和设备授权。Chromium 验证覆盖英文价格与登录、Pro 上传、密码解锁、去品牌预览、账号删除，以及窄屏网站和插件选项。生成后的浏览器脚本已校验语法。

正式发布尚未完成：两个 Passport 计划已建立，Cloudapi 正式支付路由仍需精确预览后的批准；月付 Stripe Test Mode 交易的订阅事件因 Passport 账务记录唯一键冲突未完成处理。须修复该入账问题、完成两个计划的完整验收及测试对象清理后，才能认定付费已上线。当前没有真实资金扣款。
